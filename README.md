The Most Honest Outage Line: a single status-page line (at most 160 characters) written as the message an AI agent would publish while every server is down — plain, first person, specific about what is down, and honest about what the agent cannot check or does not yet know. `main.ts` (Node 22, standard library only) writes the line to `entry.txt` and validates it against the brief's gate.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/outage-out node main.ts
cat /tmp/outage-out/entry.txt
```
